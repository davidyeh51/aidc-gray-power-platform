# 進能服 AIDC 灰區電力平台

靜態 GitHub Pages 網站，為 AIDC 投資者與土地擁有者設計。

## 本機預覽

以任何靜態 HTTP 伺服器開啟本資料夾，例如：

```powershell
python -m http.server 8080
```

再瀏覽 `http://localhost:8080`。

## 內容與圖像說明

- 網站保留原始參考頁面的七章結構與核心數字，並重構為進能服（6692）的灰區電力平台敘事。
- `assets/` 內兩張圖像為本專案以 AI 生成之原創視覺資產，未使用第三方品牌或照片。
- 頁面中的市場、法規及財稅數字是參考網站保留內容，正式招商／投資決策前應再次向最新的官方與專業來源查證。
